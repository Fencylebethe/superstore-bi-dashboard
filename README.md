# Superstore BI Dashboard

Executive Power BI dashboard built for a national retail company, completed as part of the AnalystLab Africa Data Analytics Internship (Week 2).

## Business Problem
Senior management needed an interactive dashboard to monitor sales performance, profitability, customer behavior, and regional performance across the business.

## Dataset
[Superstore Sales Dataset](https://www.kaggle.com/datasets/vivek468/superstore-dataset-final) — 9,994 orders, 21 features.

## Dashboard Features
- 5 KPI cards: Total Sales, Total Profit, Total Orders, Average Sales, Profit Margin
- 8+ visualizations: bar charts, column charts, line chart, donut chart, map, matrix table
- 2 interactive slicers: Region and Category

## Key Findings
- West region generates the highest sales, followed by East, Central, and South
- Technology is the most profitable category; Furniture has strong sales but the lowest profit margin
- Overall profit margin sits at 12%
- Consumer segment drives the most profit
- Sales show a declining trend over the observed period, warranting further investigation

## Tools Used
Microsoft Power BI (Power Query for data cleaning, DAX for custom measures)
